# Canva Build Or Import Instructions

Canva access was not used in this execution. This package is prepared for manual Canva import.

## Recommended Canva File

Name: `TP_CAMPAIGN_GOPPI_SUCCESS_COORDINATION_V1`

## Formats

- LinkedIn carousel: 1080 x 1080 px, 7 pages
- Instagram carousel: 1080 x 1350 px, 7 pages
- Facebook carousel/feed: 1080 x 1080 px, 7 pages

## Layer Groups

Create the following locked group names:

- `Background / TouchPoint Grid`
- `Image / Human Finance Moment`
- `Logo / TouchPoint`
- `Headline`
- `Supporting Copy`
- `GOPPI Definition`
- `CTA - Awareness Only`
- `CTA - Learning Corridor`
- `CTA - Conscious Spending Tool`
- `CTA - Conversation Invitation`
- `Fine Print`

## Hidden CTA Layers

All CTA variants should remain hidden by default until Nikki approves the posting stage.

## Visual Notes

- Use dark teal background `#06121a`.
- Use accent cyan/emerald from the site CTA gradient.
- Use editorial serif headline styling.
- Keep body copy large enough for mobile-feed readability.
- Do not use images that resemble Nikki for generic blog/vlog or social thumbnails.
